# Personal Portfolio

A personal portfolio website built to showcase my work, skills, projects, and journey as a developer.

This project is more than just a portfolio. It's an evolving space where I experiment with web technologies, apply what I learn, and gradually build towards becoming a well-rounded full-stack developer.

## 🚀 Project Overview

The portfolio is being developed in multiple phases, starting with the fundamentals of web development and progressively moving towards modern frontend and full-stack technologies.

The initial version focuses on building a responsive, accessible, and visually engaging website using core web technologies. Future iterations will introduce a more scalable architecture with modern frameworks, stronger type safety, and backend integration.

## 🛠️ Tech Stack

### Current Development
- **HTML5** – Semantic structure and markup.
- **CSS3** – Styling, layouts, animations, and responsive design.
- **JavaScript (Vanilla)** – Interactivity and dynamic functionality.
- **Tailwind CSS** – Utility-first styling (planned / optional).

### Future Development
- **React** – Component-based frontend architecture.
- **TypeScript** – Type safety and maintainable code.
- **Backend Technologies** – Server-side functionality and API development.
- **Database** – Data storage and management.

*The technology stack will evolve as the project progresses.*

## 🎯 Project Goals

- Build a clean, modern, and responsive personal portfolio.
- Showcase projects, technical skills, and development experience.
- Apply fundamental web development concepts through practical implementation.
- Follow accessibility and performance best practices.
- Experiment with modern UI/UX patterns and web technologies.
- Gradually transition from vanilla JavaScript to a modern React and TypeScript architecture.
- Eventually integrate backend functionality and turn the portfolio into a full-stack application.
